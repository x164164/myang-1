📖 什么是 GESP？

GESP 是 中国计算机学会（CCF）主办的“编程能力等级认证”，Python 方向分 1~8 级，60 分及格。 一级考试一般包含 判断题、选择题和编程题（具体题型与分值以当期官方公告为准）。本站内容覆盖 GESP 一至四级：一级基础语法，二级分支循环嵌套与 ASCII，三级进制、补码与枚举模拟，四级函数、排序与文件异常，跟着学就能逐级挑战！

📝 考级小技巧

① 看清符号：一个 = 是赋值，两个 == 才是比较相等；整除 //、取余 %、幂 ** 是必考符号。
② 读代码要动手：在草稿纸上一行行写下变量的值，循环题就数圈数。
③ input 是字符串：要算数先 int() 转换。
④ 缩进和冒号：if / for / while / def 行尾都要有冒号 :，下一行缩进。
